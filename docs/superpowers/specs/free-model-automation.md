# 무료/로컬 모델 자동화 활용도 개선 Spec

## 목표

Planning Copilot을 실무에서 반복 사용할 수 있도록 무료 API, 로컬 LLM, 수동 GPT 흐름을 선택하는 모델 라우터를 추가한다. 생성된 산출물은 자동 실행하지 않고 승인함과 프로젝트 기억에 보관한다.

## 범위

- 모델 설정 탭 추가
- Simulation, Ollama, Gemini, GitHub Models, Manual GPT 경로 정의
- 승인함 상태 관리 추가
- 프로젝트 기억 저장소 추가
- 로컬 야간 보고 스크립트 추가

## 안전 원칙

- API 키는 저장소에 커밋하지 않는다.
- 브라우저 저장 API 키는 사용자 로컬에만 둔다.
- 민감자료는 Ollama 같은 로컬 모델을 우선한다.
- 자동 메일 발송, SNS 게시, 공문 제출은 만들지 않는다.
