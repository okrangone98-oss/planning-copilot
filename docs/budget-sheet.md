# 예산 관리표 — 엑셀·구글 시트형 격자와 서류 연동

예산을 카드·폼으로 한 줄씩 적던 방식을 **스프레드시트 격자**로 바꾸고, 그 숫자가 결과보고·양식 채우기·`.hwpx` 내보내기에 그대로 들어가게 정리한 화면입니다.
사용자 요청: "예산관리는 구글 스프레드시트나 엑셀표의 양식을 차용해서 입력 및 관리되도록 하고, 그 숫자들이 완성되는 서류 양식에 들어가도록."

## 1. 어디에 있나

| 화면 | 쓰임 |
| --- | --- |
| `예산 편성` (사이드바 → 예산 편성) | 사업 예산을 처음 잡고 고치는 곳. 같은 격자에 지출 원장이 연결됩니다. |
| 사업 상세 → `예산·집행` 탭 | 예산과 지출 원장을 한 화면에서 대조. 격자 아래에 지출 원장이 이어집니다. |
| `샘플 양식 채우기` / `작년 결과보고서 → 올해 것으로 바꾸기` 2단계 | **예산 관리표 숫자만 불러오기** 버튼으로 격자 숫자를 양식 칸에 배치. |

## 2. 열과 계산

`비목 · 세목 · 단가 · 수량 · 편성액 · 집행액 · 잔액 · 산출근거 · 비고`

- **편성액 = 단가 × 수량**, **잔액 = 편성액 − 집행액** — 계산 칸이라 직접 고치지 않습니다.
- 합계 줄은 맨 아래에 고정되어 `편성 · 집행 · 잔액 · 집행률`과 초과 비목 수를 보여 줍니다.
- 머리글은 스크롤해도 위에 붙어 있고, 좁은 화면에서는 **표만** 자기 상자 안에서 가로로 넘어갑니다(페이지 폭은 그대로).
- 숫자 칸은 `tabular-nums`로 오른쪽 정렬, 행 높이 34px의 얇은 선 표입니다.

## 3. 입력 방법

1. **칸 클릭** → 바로 입력. `Tab`/`Shift+Tab`은 옆 칸, `Enter`/`Shift+Enter`는 위·아래 칸. 표 끝에서 `Tab`·`Enter`를 누르면 새 행이 생깁니다.
2. **Ctrl+V** — 엑셀·구글 시트에서 복사한 여러 칸(탭 구분)을 클릭한 칸부터 그대로 붙입니다. 머리글 줄이 함께 왔으면 값으로 넣지 않고 건너뜁니다. 쉼표(CSV) 표는 기존 예산 파서가 머리글·따옴표를 알아보고 표 뒤에 붙입니다.
3. **엑셀·시트 불러오기** — `.xlsx` / `.csv` / `.tsv` / `.txt` 파일, 또는 붙여넣기. `.xlsx`는 브라우저 안에서만 읽고(서버로 올리지 않음), 시트가 여럿이면 **시트 탭을 골라** 읽습니다. 읽은 결과는 넣기 전에 표로 미리 보여 주고, `아래에 덧붙이기 / 같은 비목은 채우기 / 표를 비우고 넣기` 중에서 고릅니다.
4. **내려받기** — `CSV`(엑셀에서 바로 열리는 UTF-8 BOM) · `XLSX` · `시트로 복사`(탭 구분).
5. 엑셀 파일은 `올해 추진계획서`(hwpx 전용)가 아니라 **정산·출석 자료**와 **지출 내역 가져오기**에서도 열립니다.

## 4. 집행액은 지출 원장과 한 몸

집행액의 원천은 **지출 원장**입니다. 두 곳에서 따로 계산하면 결과보고 숫자가 어긋나기 때문입니다.

- 원장에 사람이 적은 지출이 있는 비목: 격자 집행액은 **읽기 전용**이고 `원장` 배지를 답니다. 고치려면 아래 지출 원장에서 고칩니다.
- 원장에 기록이 없는 비목: 격자에서 집행액을 적을 수 있고, 그 값은 적요가 `예산 관리표에서 입력`인 지출 1건으로 원장에 남습니다(`paid`, 증빙 미확인).
  - 같은 비목에서 다시 고치면 새 건을 만들지 않고 그 1건의 금액을 바꿉니다.
  - 0으로 지우면 그 1건만 지웁니다 — 사람이 적은 지출은 건드리지 않습니다.
- 지출 예정(`planned`)은 집행액에 넣지 않고 `예정` 배지로만 보여 줍니다(잔액에서 미리 빼지 않음).

## 5. 서류로 흘러가는 길

1. 격자에서 고친 값은 `grantPlan.budgetLines`와 지출 원장(`work.expenses`)에 저장됩니다 — 화면마다 다른 사본을 두지 않습니다.
2. `buildBudgetDigestText`(`src/lib/projectDataReuse.mjs`)가 `총사업비 · 편성 총액 · 집행액 · 잔액 · 집행률`과 비목·세목별 금액을 `라벨: 값` 줄로 만듭니다.
3. 2단계의 **예산 관리표 숫자만 불러오기**가 그 글을 붙여넣기 칸에 넣고(여러 번 눌러도 `■ 예산 관리표` 구역은 하나만 남음), **자동으로 칸 나누기**가 양식의 해당 라벨 칸에 배치합니다.
4. 결과보고 `.hwpx`(`reportHwpx.mjs`)의 요약 표·예산 표와 `projectDataReuse.buildProjectDataText`의 `집행 현황` 줄도 같은 계산 함수(`budgetSummary`·`expenseSummary`)를 씁니다.

## 6. 구현 지도

| 파일 | 역할 |
| --- | --- |
| `src/lib/xlsxTable.mjs` | jszip만으로 `.xlsx` 읽기/쓰기 (시트 이름·공유 문자열·빈 칸·수식 값, CSV BOM) |
| `src/lib/budgetSheet.mjs` | 격자 행·합계, 붙여넣기, 집행액 → 원장 반영, 내려받기 표 |
| `src/components/BudgetSheet.tsx` | 격자 화면(편집·키보드·붙여넣기·툴바) |
| `src/components/BudgetImportPanel.tsx` | 파일·시트·붙여넣기 가져오기와 미리보기 |
| `src/lib/budgetImport.mjs` | 표 읽기(머리글 별칭, 편성액·집행액 열) |
| `src/lib/projectDataReuse.mjs` | 예산 숫자 블록, 블록 교체, 사업 데이터 글 |
| `src/styles/budget-sheet.css` | 격자 스타일 |
