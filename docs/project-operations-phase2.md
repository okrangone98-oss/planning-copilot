# 지출 원장·잔액·증빙·회차 인원 연동(2단계) — 설계와 사용법

2026-11-15 · Planning Copilot · PRD v1.1 2단계(FR-08·FR-09·FR-10 + 첫 화면·설정 정리)

1단계에서 만든 사업 운영(업무·일정·회차·예산) 위에 **돈이 실제로 나간 기록(지출 원장)** 과 **회차 인원 선택 기록**을 붙였습니다.
새 메뉴는 만들지 않았고, 기존 10개 메뉴와 저장 데이터(v1/v2/v3, 백업 v6/v7)는 그대로 읽힙니다.

## 1. 한눈에

| 하려는 일 | 어디서 |
| --- | --- |
| 비목별 계획·집행·잔액·집행률·초과 확인 | 사업 관리 → `상세` → `예산·집행` 맨 위 대조표 |
| 지출 한 건 적기·고치기·지우기 | `예산·집행` → `지출 추가` / 적요 누르기 / `수정`·`삭제` |
| 엑셀·구글 시트 지출 내역 붙여넣기 | `예산·집행` → `시트·CSV 가져오기` |
| 지출 원장을 시트로 다시 옮기기 | `예산·집행` → `시트로 복사`(TSV) |
| 증빙 확인 체크·증빙 참조·메모 | `예산·집행` 지출 목록의 `증빙` 칸 |
| 증빙 안 한 지출만 보기 | `증빙 미확인` 칩(요약 타일에서도 바로 열림) |
| 회차 인원(정원·신청·참석) 기록 켜고 끄기 | `회차` → `인원 켜기`/`인원 끄기` 또는 회차 수정 |
| 참석 연인원·집행·잔액을 결과보고에 넣기 | `결과보고` → `운영 실적·예산 자동 반영` → `섹션에 넣기` |
| 사업별 증빙 누락 모아 보기 | `정산 증빙` 맨 위 `지출·증빙 누락` |
| 오늘 할 일·다가오는 회차·증빙 미확인 | `시작 화면` → `오늘 할 일` |
| 화면 색 바꾸기 | `모델·보안 설정` → `화면 색 팔레트`(사이드바에서 이동) |

## 2. 저장 구조

지출은 사업별 운영 데이터(`planningCopilotProjectWork:{id}`) 안 `expenses[]`에 들어갑니다. 백업 v7에 그대로 담기므로 새 저장 키나 새 백업 버전이 필요 없습니다.

| 필드 | 뜻 |
| --- | --- |
| `budgetLineId` | `grantPlan.budgetLines`의 행 id. 비어 있으면 `비목 미지정` |
| `sessionId` | 회차 id(선택). 없는 회차를 가리키면 비웁니다 |
| `spentAt` | 지출일 `YYYY-MM-DD`(달력에 없는 날짜는 버림) |
| `vendor` / `description` | 거래처(60자) / 적요(120자) |
| `amount` | 지출 금액(0 이상 정수, 최대 1조) |
| `status` | `paid` 집행 완료 · `pending` 지출 예정 · `planned` 계획만 |
| `evidenceRef` / `evidenceNote` | 증빙 참조(전표 번호 등) / 증빙 메모 |
| `evidenceChecked` | 증빙 확인 여부(체크박스) |
| `createdAt` / `updatedAt` | 기록 시각 |

- **계획액의 유일한 원천은 여전히 `grantPlan.budgetLines`** 입니다. 지출은 금액을 계획에서 복제하지 않고 비목 id로만 가리킵니다. 그래서 비목 금액을 고치면 잔액이 즉시 따라 바뀌고, 이중 합산이 생길 수 없습니다.
- 지출을 고치면 `changes[]`에 `entityType: "expense"`로 전후 값·사유가 남습니다(금액은 `250,000원` 표기).
- 상한: 지출 **600건**(넘으면 `addExpenses`가 `skipped`로 돌려주고 조용히 버리지 않음).

## 3. 계산 규칙(화면과 같은 숫자)

| 값 | 정의 |
| --- | --- |
| 계획액 | `budgetLines`의 `단가 × 수량` 합계(비목별 합) |
| 집행액 | **집행 완료(paid) + 지출 예정(pending)** — 이미 나갔거나 나가기로 한 돈 |
| (참고) 계획만 | `planned` 금액. **잔액에서 빼지 않음** |
| 잔액 | 계획액 − 집행액 |
| 집행률 | 계획액이 있으면 `집행액 / 계획액`(반올림 %), 계획 0에 지출이 있으면 100% |
| 초과 | 비목별 집행액 > 계획액. 초과한 비목 이름과 초과 금액을 경고로 보여 줌 |
| 비목 미지정 | 계획 행을 찾지 못한 지출. 합계에는 넣고 비목 대조표 마지막 줄에 모아 표시 |

- 같은 비목에 여러 세목이 있으면 대조표는 **비목 합**으로 보여 주고, `세목별로 보기`를 열면 세목별 계획·집행·잔액이 나옵니다.
- 요약 타일: 계획액 / 집행액(완료+예정) / 잔액 / 집행률 / 증빙 미확인.
- 증빙 대상은 **집행 완료·지출 예정**만입니다. `계획만` 지출은 증빙 칸에 `해당 없음`으로 표시합니다.

## 4. 지출 가져오기(엑셀·구글 시트·CSV)

- 탭 복사(TSV), CSV, Markdown 표(`|`)를 모두 읽습니다. 구분자는 탭 → `|` → 쉼표 순으로 자동 판별합니다.
- 머리글 이름으로 열을 찾습니다: 사용일자/지출일/일자/날짜 · 거래처/사용처/가맹점 · 적요/내역/사용내역 · 금액/지출액/결제금액 · 비목/예산비목 · 세목 · 상태/집행상태 · 증빙/전표 · 비고. 머리글이 없으면 `날짜 → 거래처 → 적요 → 금액 → 비목` 순서로 읽고 그 사실을 알려 줍니다.
- 날짜: `2026-11-03`, `2026.11.3`, `2026/11/03`, `20261103`, `26.11.3`을 `YYYY-MM-DD`로 바꿉니다. 못 읽으면 날짜만 비우고 행은 살립니다.
- 상태: 집행 완료·지출예정·계획만·O/X 등을 읽고, 없으면 **집행 완료**로 넣은 뒤 그 사실을 알려 줍니다.
- 금액: `48,000`, `48000원`, `4.8만원`을 숫자로 읽습니다. 금액을 못 읽은 줄은 넣지 않고 이유를 남깁니다.
- 비목: 이름을 계획 행과 맞춰 id로 바꿉니다(정확히 → 비목만 → 세목 → 부분 일치 순). 끝까지 못 맞추면 `비목 미지정`으로 넣고 건수를 보여 줍니다. **금액은 잃지 않습니다.**
- 가져오기는 **덧붙이기만** 합니다(원장을 지우고 바꾸는 모드는 두지 않음 — 나간 돈 기록을 실수로 지우지 않게). `같은 날짜·금액·적요는 건너뛰기`가 기본 켜짐입니다.
- 미리보기에서 읽은 줄 수·합계·더할 건수·중복·비목 미지정·경고를 먼저 보여 주고, 누를 때만 저장합니다.

## 5. 회차 인원 기록(선택)

- `Session.trackAttendance`가 **켜진 회차에서만** 정원·신청·참석 입력칸이 열립니다. 끄면 입력칸이 사라지고 적어 둔 값은 보관한 채 **합계에서만** 빠집니다.
- 저장 값이 없는 예전 회차는 인원이 하나라도 적혀 있으면 켜짐, 전부 비어 있으면 꺼짐으로 읽습니다(기존 합계가 달라지지 않게).
- 인원 칸을 비우면 `0`이 아니라 **`null`(미입력)** 로 저장합니다. 화면에는 `미입력`, 합계에서는 빠지고 `참석 미입력 N회차`로 따로 알려 줍니다.
- 집계: 취소 회차·인원 기록 꺼진 회차를 빼고 `정원·신청·참석` 합계. 통계 타일에 `인원 기록`·`집계 제외`·`정원/신청/참석 합계`가 함께 나옵니다.
- 회차 표에서 `인원 켜기`/`인원 끄기`를 바로 누를 수 있고, 변경 이력에 `인원 기록 예/아니오`로 남습니다.

## 6. 결과보고·내보내기 연동

`결과보고` 화면 위에 **운영 실적·예산 자동 반영** 패널이 붙습니다.

- 참석 연인원(적힌 값만 합계) · 완료 회차 참석 · 편성 예산 · 집행액 · 잔액 · 증빙 미확인을 보여 줍니다.
- `0명`(적힌 0) · `미입력`(합계에서 빠짐) · `집계 제외`(인원 기록 꺼짐)를 문장으로 구분해, 미입력을 0명으로 오인하지 않게 합니다. 인원 기록을 켠 회차가 하나도 없으면 `인원을 기록한 회차가 없습니다(0명이 아니라 집계 제외)`라고 적습니다.
- `섹션에 넣기`: 고른 섹션 **끝에 덧붙입니다**(기존 글은 지우지 않음). 이미 `[자동 집계`가 있으면 다시 넣지 않고 안내합니다. `복사`로 다른 양식에 붙일 수도 있습니다.
- `워크브레인 내보내기` Markdown에도 `운영 실적·집행 현황` 절이 함께 실립니다(회차·참석 표 + 비목별 계획/집행/잔액 표 + 빠진 것 안내). 운영 데이터가 없으면 빈 절을 만들지 않습니다.

## 7. 정산 증빙 화면

`정산 증빙` 맨 위에 `지출·증빙 누락` 블록이 생겼습니다.

- 현재 사업: 지출 건수 · 증빙 대상 · 증빙 미확인(건·금액)과 미확인 지출 목록(최대 8건).
- 다른 사업에 미확인이 있으면 사업별 칩으로 모아 보여 주고, 누르면 그 사업의 `예산·집행` 탭으로 이동합니다.
- 지출 기록이 없으면 “아직 지출 기록이 없습니다”로 안내하고 예산·집행 탭으로 보냅니다.

## 8. 첫 화면·사이드바 정리

- `시작 화면` 오늘 할 일 타일: 지연 · 오늘 마감 · 7일 안 마감 · **증빙 미확인** · **다가오는 회차** · 운영 중 사업.
- `다가오는 회차`(30일 안, 가까운 순 4개)와 `증빙 미확인`(사업별 건수·금액)을 바로 누를 수 있습니다.
- `다음 권장 행동` 순서: 지연 업무 → 오늘 마감 → **증빙 미확인** → 다가오는 회차 → 계획 확정 → 운영 업무 만들기 → 예산 편성.
- 색 팔레트(현장 초록/행정 파랑/문서 먹색)는 사이드바에서 `모델·보안 설정` 화면 안으로 옮겼습니다. 고른 색은 그대로 기억됩니다.

## 9. 호환성·마이그레이션

| 상황 | 처리 |
| --- | --- |
| 예전 운영 데이터(지출 없음) | `expenses: []`로 읽음. 업무·회차·예산 그대로 |
| 예전 회차(인원 기록 필드 없음) | 인원이 적혀 있으면 켜짐, 비어 있으면 꺼짐 → 기존 합계 유지 |
| 예전 인원 값(0으로 저장돼 있던 값) | 숫자 0은 `0명`으로 유지(미입력과 구분) |
| 백업 v6 이하 | 지출 없이 복원(사업·예산·보고서는 그대로) |
| 백업 v7 | `expenses`·`trackAttendance`까지 그대로 복원 |
| 비목 행 삭제·교체 | 그 지출은 `비목 미지정`으로 남고 금액은 합계에 유지(조용히 사라지지 않음) |
