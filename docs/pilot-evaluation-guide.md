# 외부 사용자 파일럿·유료화 검토 안내

> **상태: 준비 문서.** 이 문서를 쓰는 시점에 외부 사용자 파일럿은 **실시하지 않았고, 어떤 이용량·비용·지불의사(WTP)도 측정하지 않았습니다.** 6장의 평가표는 빈칸이며, 측정한 사람이 실제 값만 적습니다. 추정치나 가정을 측정값처럼 채우지 않습니다.

이 문서는 두 가지에 씁니다.

1. 외부 실무자 3~5명에게 이 앱을 맡길 때, 그대로 복사해 보낼 수 있는 안내
2. 파일럿이 끝난 뒤 유료화를 판단할 때 볼 운영비·보안·지불의사 평가표

---

## 1. 파일럿 규모와 기간

| 항목 | 값 |
| --- | --- |
| 대상 | 센터·마을활동·컨설팅 실무자 3~5명(초대 기준) |
| 기간 | 2주 |
| 오리엔테이션 | 30분(화면 공유 1회) |
| 중간 확인 | 7일째 10분 |
| 마무리 인터뷰 | 15분 |
| 준비물 | 크롬 또는 엣지가 설치된 PC. 설치·회원가입·결제 없음 |

파일럿은 **업무 데이터가 아니라 연습용 사업 1개**로 시작합니다. 실제 공고문·주민 명단·정산 증빙 원본을 처음부터 넣지 않습니다.

## 2. 배포 전에 운영자가 확인할 것

접속 주소: **https://okrangone98-oss.github.io/planning-copilot/**

1. `모델·보안 설정` → **이용량·보안·운영비 자가진단** 카드 세 장을 연다.
2. 아래 상태인지 그대로 읽어 확인한다(화면에 저장된 값만 세어 표시한다).

| 확인 항목 | 새로 시작하는 브라우저에서 기대되는 값 |
| --- | --- |
| 저장된 사업 | 0개 |
| 지출 원장 · 회차 · 업무 | 0건 · 0회 · 0개 |
| localStorage | 0KB(사용량은 앱을 쓰면서 늘어난다) |
| 개인정보 마스킹 | 켜짐 |
| 외부 AI 전송 | 없음(기본 경로가 템플릿 모드일 때) |
| 저장소 키 흔적 | 0건 |
| 백업 파일 키 | 포함 없음 |
| 앱 지출 합계 | 월 0원 |

3. 참가자마다 **자기 브라우저**에서 접속하게 한다. 링크를 같이 열어도 데이터는 서로 섞이지 않는다.
4. 참가자에게 3장(데이터 저장 원칙)과 4장(개인정보 수칙)을 먼저 읽히고, 읽었다는 답을 받는다.

## 3. 데이터가 어디에 남는가 (참가자에게 그대로 보낼 문장)

- 이 앱은 **서버가 없습니다.** 사업 정보, 예산, 업무, 회차, 지출 원장, 승인함, 프로젝트 기억은 **지금 쓰는 브라우저의 저장 공간(localStorage)에만** 남습니다.
- 계정·로그인이 없으므로 **다른 사람과 자동으로 공유되지 않습니다.** 반대로, 같은 주소라도 다른 브라우저·다른 기기·시크릿 창에서는 **내 데이터가 보이지 않습니다.**
- 브라우저 데이터를 지우거나(방문 기록·사이트 데이터 삭제) 앱 주소가 바뀌면 **데이터가 사라집니다.** 그래서 `백업·가져오기`에서 **백업 파일 받기**로 JSON을 받아 두는 것이 유일한 보관 방법입니다.
- 백업 파일에는 사업·예산·업무·회차·지출·승인함·기억이 담기고, **모델 설정과 API 키는 담기지 않습니다.** API 키는 탭을 닫으면 사라지도록 메모리에만 둡니다.
- 브라우저 저장 공간은 보통 5MB 안팎입니다. `모델·보안 설정`의 자가진단에서 사용량과 남은 공간을 KB 단위로 볼 수 있습니다.

## 4. 개인정보·외부 AI 수칙 (지키지 않으면 파일럿 중단)

1. **주민등록번호·계좌·카드·연락처·주소가 든 실제 문서는 올리지 않습니다.** 연습용으로 만든 가짜 데이터나 공개된 공고문만 씁니다.
2. 개인정보 마스킹은 기본으로 켜져 있습니다. 끄지 않습니다. 다만 마스킹은 **정해진 모양을 찾아 가리는 방식**이라 모두 잡지는 못합니다. 원문을 붙여넣기 전에 한 번 더 눈으로 확인합니다.
3. 무료 API 키(OpenRouter·Groq·Gemini)를 넣어 쓰는 경우, **프로젝트 입력란과 일치하는 저장 자료 최대 3건이 그 서비스로 전송**됩니다. 개인정보가 든 자료로는 실행하지 않습니다.
4. 외부로 나가는 것이 걱정되면 **템플릿 모드**를 그대로 씁니다. 템플릿 모드는 AI를 호출하지 않고, 외부 전송이 0건이며 0원입니다.
5. 파일럿에서 문제(데이터 유실, 남에게 보이면 안 되는 내용 노출, 결제 요구 화면)가 보이면 **즉시 사용을 멈추고 알려 주세요.** 화면 캡처는 개인정보가 없는 부분만 보냅니다.

## 5. 4단계 사용법 (파일럿 과제)

앱의 문서·예산 흐름은 네 화면이 한 줄로 이어집니다. 어느 화면에서 멈춰도 화면 하단에 같은 진행률과 `다음 단계로 이동`이 남아 있습니다.

| 단계 | 화면 | 파일럿에서 할 일 |
| --- | --- | --- |
| 0 | `사업 관리` | 연습 사업 1개를 만들고 마감일·상태를 넣는다 |
| 0 | `공고 해석` | 공개된 공고문을 붙여넣고 문제정의·활동·예산 계획을 한 번 적는다 |
| 1 | `예산 편성` | 프리셋을 하나 골라 비목·세목·단가·수량을 채우고 합계를 확인한다 |
| 2 | `정산 증빙` | 체크리스트에서 실제로 확인 가능한 항목만 체크하고, 지출 1~2건을 원장에 적는다 |
| 3 | `결과보고` | 결과보고 초안을 채우고 `.hwpx`로 내려받아 열어 본다 |
| 4 | `워크브레인 내보내기` | Markdown으로 내보내 파일이 열리는지 확인한다 |
| — | `샘플 양식 채우기` | 기관 양식(.hwpx)이 있으면 올려 칸이 채워지는지 본다 |
| — | `모델·보안 설정` | 자가진단 카드로 이용량·보안·운영비를 확인하고, JSON 백업을 한 번 받는다 |

과제는 **한 사람당 한 번, 60~90분** 분량입니다. 막히는 지점과 걸린 시간을 적어 두면 그 자체가 가장 쓸모 있는 기록입니다.

### 6-5. 유료화 판단 기준 (측정이 아니라 사전 합의용 초안)

아래는 **아직 정한 적 없는 기준의 초안**입니다. 파일럿 전에 팀이 숫자를 확정하고, 측정이 끝난 뒤 그 기준에 대서 판단합니다.

- 초대 3~5명 중 **2주 뒤에도 스스로 여는 사람이 3명 이상**
- 4단계 과제를 **도움 없이 끝낸 사람이 절반 이상**
- 보안 사고 **0건**, 백업 복원 성공 **100%**
- 지불의사 **5,000원 이상을 말한 사람이 2명 이상**
- 1인당 월 운영비(AI 포함)가 **지불의사 금액의 절반 이하**

하나라도 크게 어긋나면 유료화보다 무료 배포·내부 사용을 먼저 봅니다.

## 7. 기록 규칙

- **측정한 값만** 적습니다. 표본이 3~5명이면 "평균"은 참고용이고, 일반화된 시장 수치로 쓰지 않습니다.
- 추정한 값은 `추정`이라고 표시하고 측정값과 섞지 않습니다.
- 참가자 이름·연락처·소속은 인터뷰 기록에 남기되, 공유용 문서에는 이니셜로 바꿉니다.
- 앱 화면 캡처를 공유할 때는 사업명·주민 명단·계좌가 보이지 않는지 확인합니다.

## 8. 지금 구조에서 유료화까지 남은 일

이번 단계는 **정적 앱의 제품화 마무리**이고, 유료화 자체는 아직 범위 밖입니다. 실제로 과금을 하려면 아래가 더 필요합니다.

| 필요한 것 | 지금 상태 |
| --- | --- |
| 계정·로그인 | 없음(브라우저 로컬 전용) |
| 결제·구독 관리 | 없음(결제 화면·연동 없음) |
| 이용량 집계·한도 적용 | 없음(자가진단 표시만, 서버 집계 없음) |
| 데이터 동기화·다중 기기 | 없음(백업 JSON 수동 복원) |
| 고객 문의·장애 대응 창구 | 없음 |

이 다섯 가지가 없는 상태에서는 **"결제했는데 데이터가 사라졌다"** 를 막을 방법이 없습니다. 그래서 파일럿은 무료로만 진행하고, 유료화 판단은 6장의 측정값이 모인 뒤에 합니다.
