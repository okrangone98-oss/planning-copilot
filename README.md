## 첫 화면과 메뉴

앱을 열면 메뉴 목록 대신 **업무 홈**이 먼저 나옵니다. 맨 위에는 큰 버튼 두 개만 둡니다 — **`🔄 작년 결과보고서 → 올해 것으로 바꾸기`**(주요)와 **`📄 새 계획서·양식 채우기`**(보조). 그 아래에 지금 사업의 상태(진행률·마감·비목 수)와 오늘 할 일을 보여 주고, 문서·정산 흐름과 읽어 둔 양식은 `다른 작업`을 열었을 때만 나옵니다.

사이드바는 실제로 매일 쓰는 **10개 메뉴**만 남겼습니다.

- `업무 홈`: 시작 화면, 사업 관리
- `문서·예산 실무`: 공고 해석, 샘플 양식 채우기, 예산 편성, 정산 증빙, 결과보고, 워크브레인 내보내기
- `설정`: 모델·보안 설정, 백업·가져오기

처음 만든 실험 화면(AI 사무국, 업무 관제탑, 질문 받기, 문제정의, 성과지표, 승인함, 시각자료, 프로젝트 링크 등)은 지우지 않고 사이드바 맨 아래 **`실험실`**을 열었을 때만 보입니다. 화면 코드와 저장 데이터는 그대로 남아 있어 이전 작업이 사라지지 않습니다.

`예산 편성` · `정산 증빙` · `결과보고` · `워크브레인 내보내기` 네 화면에서는 화면 하단에 진행률과 `다음 단계로 이동` 버튼이 **고정**되어 문서가 아무리 길어도 다음 단계가 보입니다. 좁은 화면(390px)에서는 예산 편성표가 `비목·세목·금액` 요약 한 줄로 접혀 있고, 누르면 그 행의 상세 입력이 펼쳐집니다. 모바일에서는 아래 탭바(홈·사업·예산·양식·전체 메뉴)로 이동합니다.

### 화면 디자인 기준

색·글자·여백은 [k-style-ui-ux](https://github.com/vmc-inner-circle/k-style-ui-ux) 파운데이션에서 뽑은 토큰만 씁니다(`src/styles/tokens.css`).

- 한국어는 어절 중간에서 끊지 않습니다(`word-break: keep-all`), 버튼 글자는 한 줄로 유지합니다.
- 터치 타겟은 44px 이상, 본문 읽기 폭은 880px로 제한합니다.
- 팔레트는 `현장 초록`(기본) · `행정 파랑` · `문서 먹색` 세 가지이며, 사이드바 아래에서 바꾸면 브라우저에 기억됩니다.

### 시트 복붙 · 한글(.hwpx) 변환

- `예산 편성`의 **구글 시트·CSV 붙여넣기로 채우기**에 시트에서 복사한 줄(탭·쉼표·Markdown 표)이나 CSV 파일을 넣으면 비목·세목·단가·수량·산출근거·비고로 읽어 표에 넣습니다. 머리글 순서가 달라도 열 이름으로 찾고, 합계 행은 건너뜁니다.
- **작년 결과보고서 → 올해 것으로 바꾸기**는 첫 화면의 큰 버튼으로 들어가는 3단계 화면입니다. ① 작년 결과보고서(`.hwpx`)를 올리고 ② 올해 추진계획서(`.hwpx`)·정산 엑셀(CSV)·실적 메모를 넣으면 ③ 바뀐 항목만 확인하고 `.hwpx`로 내려받습니다. 작년 문서의 **표 칸뿐 아니라 일반 문단에 적힌 `가.사 업 명: …`, `1)총 운영회차: …` 줄과 문서 제목**까지 읽어 연도·값을 갈아끼우고, 확신이 낮은 칸은 자동으로 체크하지 않아 사람이 확인하게 둡니다. 자세한 규칙은 [전년도 결과보고서 이양](docs/year-carryover-simple-flow.md)에 정리했습니다.
- `샘플 양식 채우기`에서는 **연습 양식**을 버튼 한 번으로 읽어 칸 모양을 익힐 수 있고, 카톡·메모·회의록 글을 통째로 붙여넣으면 알맞은 칸으로 나눠 보여 준 뒤 체크한 칸만 채웁니다. 채운 값은 **브라우저 안에서 원본 .hwpx 서식 그대로 들어가 `.hwpx` 파일로 바로 내려받습니다**(터미널·로컬 서버 필요 없음). kordoc `fill`/`patch`용 JSON·명령과 로컬 브릿지(`node scripts/kordoc-bridge.mjs`)는 보조 옵션으로 접어 두었습니다. 자세한 규칙은 [kordoc 양식 규격 채우기](docs/kordoc-smart-fill.md)에 정리했습니다.
- `결과보고` 화면에는 작성한 섹션과 회차·예산 자동 집계를 한글 결과보고서 한 장으로 묶는 **`.hwpx 내려받기`** 가 있습니다. 내장 최소 템플릿(`public/hwpx/report-base.hwpx`)에 제목·요약 표·섹션·예산 표를 붙여 브라우저에서 바로 만듭니다.
- `워크브레인 내보내기`의 Markdown → 새 .hwpx 문서 변환은 kordoc `generate`가 맡습니다(① .md 내려받기 ② `npx kordoc generate <파일>.md -o <파일>.hwpx --preset 보고서` 명령 복사 ③ 로컬 브릿지).

## 실행 방법

개발 중에는 아래 명령으로 실행합니다.

```bash
npm install
npm run dev
```

배포 파일은 GitHub Actions가 자동으로 빌드해 GitHub Pages에 올립니다.

```bash
npm run build
```

## 무엇을 하는 도구인가

- PDF, Word, 텍스트 공고문을 읽고 중요한 내용을 정리합니다.
- PDF, DOCX, HWPX 파일에서 브라우저 안에서 텍스트를 추출합니다.
- 공고·기관 양식(HWPX·DOCX·PDF)을 올리면 목차·표·빈칸 구조를 읽어 그 구조 그대로 내용을 채웁니다. AI 호출이 실패해도 프롬프트 복사와 규칙 기반 채우기로 이어집니다.
- 부처별 사업계획서 양식 차이를 반영해 작성 흐름을 잡습니다.
- 좋은 사례를 모아 두고 현재 공고와 맞는 참고 내용을 찾아옵니다.
- 사용자의 아이디어를 지우지 않고 문제정의, 실행계획, 성과지표로 바꿉니다.
- 국고보조사업 비목별 예산 편성표, 정산 증빙 체크리스트, 결과보고서 골격을 프리셋으로 바로 시작합니다.
- 템플릿·Ollama·무료 API(OpenRouter Free, Groq, Gemini, EXAONE, GitHub Models, AMD Token Lab, 로컬 프록시) 중에서 실행 경로를 고릅니다. 키는 브라우저 메모리에만 둡니다.
- 여러 정부·공모·자체 사업을 `사업 관리` 보드에서 나눠 두고 전환하며 작업합니다. 사업마다 입력값·예산·양식 작업이 따로 저장됩니다.
- 외부 AI·복사·내보내기로 나가기 전에 주민번호·연락처·이메일·계좌·카드·주소·성명을 자동으로 찾아 `[연락처_1]`처럼 가립니다(브라우저 안에서만 동작).
- 사업계획서·예산·정산·결과보고를 david-workbrain 규격 Markdown 한 편으로 내보내고, my-workbench·Notion으로 이어갑니다.
- Google Drive와 로컬 저장을 함께 사용합니다.
- Mermaid 기반 시각자료 초안을 만들 수 있습니다(실험실).
- Jira, Notion, Google Sheet, Google Drive 링크를 프로젝트별로 연결할 수 있습니다(실험실).
- 구글 시트·엑셀에서 복사한 예산표를 그대로 붙여넣어 비목을 채웁니다.
- 결과 Markdown을 kordoc 명령이나 로컬 브릿지로 한글(.hwpx)로 바꿀 수 있게 안내합니다.
- 올린 양식에 값을 채우는 일과 결과보고 문서 만들기는 브라우저 안에서 끝납니다(`src/lib/browserHwpxFiller.mjs`·`src/lib/reportHwpx.mjs`).

## 권장 사용 순서

1. `시작 화면`에서 지금 하려는 일을 고르거나, `공고 해석`에 공고문(PDF·DOCX·HWPX·TXT)을 올려 분석합니다.
2. `샘플 양식 채우기`에 기관 양식을 올려 목차·표 구조를 확인하고 내 사업 정보로 채웁니다.
3. `예산 편성`에서 프리셋을 적용하거나 시트를 붙여넣어 비목표를 만듭니다.
4. `정산 증빙`에서 증빙 항목을 순서대로 확인하고 메모를 남깁니다.
5. `결과보고`에서 기관 양식 순서대로 초안을 채웁니다.
6. `워크브레인 내보내기`로 david-workbrain·Notion에 넣을 Markdown을 만들고, 필요하면 kordoc으로 .hwpx를 만듭니다.
7. `백업·가져오기`에서 파일로 저장하거나 Google Drive에 백업합니다.

AI 사무국·관제탑·사례 모으기·시각자료 같은 실험 기능은 `실험실`을 열어 같은 순서 사이에 끼워 쓸 수 있습니다.

## 저장 방식

기본 저장은 사용 중인 브라우저에 됩니다. 다른 컴퓨터에서도 이어서 쓰려면 `백업·가져오기`에서 백업 파일을 내려받거나 Google Drive 백업을 설정하세요.

중요한 문서 원본은 Google Drive에 보관하고, 앱에는 텍스트 추출본과 참고 메모를 저장하는 방식을 권장합니다.

## 외부 작업공간 연결

`실험실 → 프로젝트 링크`에서 Jira, Notion, Google Sheet, Google Drive 링크를 저장할 수 있습니다.

현재는 링크 연결을 우선 지원합니다. 이후에는 아래 기능으로 확장할 수 있습니다.

- Jira 작업 자동 생성
- Notion 기획 노트 저장
- Google Sheet 성과지표 자동 업데이트
- Google Drive 원본 문서 폴더 동기화
